一页纸复习

全书压成一页。每条都能在对应章导航里点回原文页。

第1章 绪论

  • 弧焊电源＝对电弧供电、提供电流电压并具有焊接工艺电气特性的装置，是电弧焊机核心；三作用：引弧 / 稳弧 / 调弧。
  • 分类四线索：电流种类（直/交/脉冲）、关键器件（变压器/整流器/逆变器）、输出特性（平/缓降/恒流）、适用方法（焊条/埋弧…）。
  • 发展：机械调节 → 电磁控制 → 电子控制（晶闸管整流式 / 脉冲式 / 逆变式）；现代特征＝电力电子器件＋电子/数字控制、精确化柔性化智能化，代价是抗噪性降低、维修要求高。

第2章 基本电气特性 ★

  • 电弧＝气体介质中强烈而持久的放电（低电压、大电流）；前提：两电极有电位差＋存在带电粒子。
  • 带电粒子来自气体电离（热/场致/光/碰撞）与电极电子发射（热/光/重粒子碰撞/强电场自发射）——二者是形成与稳定电弧的充要条件。
  • 引弧：接触（短路→拉开 2–4 mm→燃弧）／非接触（高频或高压脉冲）。
  • 三区：$U_f=U_K+U_C+U_A$；$U_K$ 3–20 V，$U_A$ 2–10 V，$U_C$ 与弧长成正比。
  • 静特性三段：下降 / 水平 / 上升；焊条电弧焊工作在水平段。
  • 交流电弧三特点：周期熄灭重燃、波形畸变、热惯性明显；五措施：加感抗、提频率、提空载电压、改波形、叠加高压。
  • 四要求：引弧容易、电弧稳定、参数稳定、调节范围够宽；三特性：外特性（静态）、调节特性（不同强度）、动特性（动态）。
  • 外特性 $U_y=E-I_y r_o$；$r_o>0$ 下降、$r_o=0$ 平；形状选择：焊条→恒流带外拖，等速送丝（细丝）→平/缓降（自身调节），变速送丝（粗丝、埋弧）→陡降/恒流（弧压反馈）。
  • 空载电压 $U_0>(1.8\sim2.25)U_f$（交流）；稳态短路电流 $I_{wd}$（$U_y=0$）。
  • 调节特性＝外特性曲线族；$I_{2\max}\ge100\%I_{2r}$，焊条 $I_{2\min}\le20\%I_{2r}$；约定负载：焊条 $U_2=20+0.04I_2$、TIG $10+0.04I_2$、MIG $14+0.05I_2$、埋弧 $20+0.04I_2$（$I_2\le600$ A）。
  • 动特性：引弧"空载—短路—负载"、CO₂ 短路过渡反复空载/短路；指标看短路电流增长速度与恢复；评价看飞溅率。

第3章 弧焊变压器

  • 原理：空载（$E=4.44fN\Phi_m$）／负载（等安匝、磁动势平衡）；$k_M=0\sim1$ 反映耦合，$k_M$ 小则漏抗大。
  • 两条路线获得下降外特性：串电抗器、增强漏磁；外特性 $U_f=U_0-I_fX_z$，曲线是以 $U_0/X_z$、$U_0$ 为长短轴的四分之一椭圆。
  • 三类增强漏磁：BX1 动铁心（改气隙→改 $X_z$）、BX3 动绕组（改绕组间距，粗调/细调）、BX6 抽头（改有效匝数，分级）。
  • 电抗器式：调气隙式可连续调节；另有分体式。

第4章 电子控制型

  • 电力半导体是"电力电路—电子电路"的连接结点，核心是小控大。
  • 晶闸管＝导通可控的二极管：反向必阻断；正向门极正压才导通；导通后只要正向阳极电压在就维持。参数：$U_{BO}$、$U_{RO}$、$U_{Te}$（选型留 2~3 倍）。
  • MOSFET：电压控制、驱动功率小；但耐压耐流低、导通损耗大。GTR：通流大但基极电流大。IGBT＝二者优点合一。
  • 反馈造形状：电压负反馈→恒压；电流负反馈→陡降；电流截止负反馈→恒流；电压电流复合→斜特性。

第5章 晶闸管弧焊整流器

  • 组成：三相降压变压器 → 晶闸管整流（AC-DC）→ 滤波电感 → 移相触发/驱动 → 参数与特性控制。
  • 主电路与输出：三相半控桥 $1.17U_2(1+\cos\alpha)$；三相全控桥 $2.34U_2\cos\alpha$；六相半波 $1.35U_2\cos\alpha$（电流只流一只 SCR，管压降损耗小）；双反星形带平衡电抗器 $1.17U_2\cos\alpha$（两桥并联、电流均分）。
  • 触发电路：脉冲要有幅值功率、前沿陡、与主电路同步、移相范围够；正弦波移相（需 90° 相位差）、锯齿波同步切割式。

第6章 逆变式

  • 结构 AC-DC-AC-DC：输入整流 → 逆变（IGBT 约 20 kHz）→ 高频变压器降压 → 输出整流滤波。
  • 轻的根据：$U$、$B_m$ 定了以后 $f\propto1/(NS)$，频率上去匝数与铁心截面就下来。
  • 四条优点：高效节能、轻小、电气性能优良、工艺性能好；代价：器件要求高、电路复杂。
  • 单端（变压器单向电流：正激/反激）vs 双端（双向：推挽/半桥/全桥，全桥 $U_d$ 直接加在变压器上、磁利用率高）。
  • 控制：PWM 定频调宽（占空比定电压）、PFM 定宽调频；外特性/调节/动特性都由电子电路给。
  • 重量对照：ZX7 逆变式 ≈66 kg，BX1 ≈300 kg，ZX5 ≈220 kg。
