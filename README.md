## 用法

1. Obsidian「打开文件夹作为库」指向本目录；
2. 版式：`.obsidian/snippets/折叠属性.css` 已启用（frontmatter 折成一行，鼠标移入展开）；`讲义页排版.css` 未启用，需要时在 设置 → 外观 → CSS 片段 里勾选；
3. 页码：页脚 `Slide n` 与 PDF 页序全文一致（273/273 校验），故 `幻灯片 n = PDF 第 n 页`，无偏移；
4. 每页都内嵌页图 `pNNN.jpg`——曲线、波形、电路拓扑以图为准；文字层/OCR 只作检索与引用辅助。

## 三条硬规则

1. **红字＝重点**：课件红字转 `==高亮==`，每页 `> [!important]` 汇总，全库 99 条。
2. **不编内容**：正文来自课件文字层；纯图片页只写「以页图为准」并附 OCR 机读文本（标注可能错字）。
3. **不编页码**：所有页码来自 PDF 页序，链接直达。

## 重跑

```bash
python3 tools/extract.py "99 素材/弧焊电源PPT.pdf" tools/pages.json
python3 tools/build.py                      # 讲义页 + 章导航 + 自动索引（先出 meta.json）
python3 tools/cards12.py && python3 tools/cards34.py && python3 tools/cards56.py   # 概念卡（依赖页标题）
python3 tools/build.py                      # 再跑一次：把概念卡回链写进讲义页
python3 tools/pages_extra.py && python3 tools/pages_extra2.py
python3 tools/check.py     # 死链 / 统计校验
```

> 内容取自课件文字层与页图；图形数值与公式以原课件为准。
